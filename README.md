# 大闹阴曹 · 归山

一个用**纯 C** 写的轻度肉鸽（Roguelite）实时动作游戏。零第三方依赖，单文件源码，终端里跑。

> 孙悟空大闹地府、勾销生死簿之后，轮回失序，鬼门洞开。
> 花果山一只没名没姓的小猴追着一缕毫毛跌进阴曹，手里只有一根齐眉棍。
> 黄泉路 → 奈何桥 → 枉死城 → 阎罗殿，一路打回花果山。

---

## 一、直接开玩

**Windows**：双击 `diyu.exe`，或在终端里运行：

```
run.bat
```

推荐用 **Windows Terminal**（自带 UTF-8 与 ANSI 彩色支持）。若用老版 cmd 出现中文乱码或画面换行，
可以在窗口里先执行 `chcp 65001`，并把窗口拉宽到 100 列以上（游戏会自动尝试调整）。
Linux / macOS 用支持 ANSI 的终端运行编译出的 `diyu` 即可。

> 游戏用 `difu_save.dat` 记录元魂与永久强化，会自动生成在 exe 同目录。

## 二、操作

| 按键 | 作用 |
| --- | --- |
| `W A S D` / 方向键 | 移动（同时决定出手朝向） |
| `J` / `空格` | 攻击（按住可连续出手，带软锁定自动微调朝向） |
| `K` / `Shift` | 冲刺，短暂无敌，有冷却 |
| `Q` | 服下回魂丹，回复 42 点生命 |
| `1 2 3 4` | 切换兵器（未解锁的会提示价格） |
| `E` | 清场后前往下一殿 |
| `P` / `Esc` | 暂停 / 查看说明；暂停时按 `X` 放弃本轮 |
| 数字键 / `Enter` | 菜单、赐福、孟婆亭选择 |

## 三、玩法

### 四重地府

| 关卡 | 殿数 | 特色 |
| --- | --- | --- |
| 黄泉路 | 3 | 断碑与彼岸花，孤魂野鬼为主 |
| 奈何桥 | 3 | 上下是忘川水，只能在桥面作战，无路可退 |
| 枉死城 | 3 | 石柱牢笼阵，鬼差与牛头马面列阵 |
| 阎罗殿 | 1 | Boss 阎罗王：五鬼扇、万魂环、召阴兵、阎罗冲 |

每殿 2~3 波敌人。清场后先在**判官赐福**里三选一，再进**孟婆亭**消费，然后按 `E` 推进。

### 四种兵器

| 兵器 | 解锁价 | 特点 |
| --- | --- | --- |
| 齐眉棍 | 初始 | 横扫范围大，攻守兼备 |
| 追魂枪 | 45 灵魂 | 刺得最远，带击退 |
| 断业刀 | 100 灵魂 | 一击重创，范围极广，出手慢 |
| 青冥剑 | 70 灵魂 | 出手极快，适合贴身连击 |

每种兵器可在孟婆亭淬炼到 Lv4，每级 +28% 伤害。

### 灵魂经济

- 击杀掉落**灵魂**，走近自动吸取（有磁吸范围）。
- 孟婆亭：回魂丹 25、淬炼兵器 30 起、淬体 60（生命上限 +20）、孟婆汤 40（回满）、解锁/切换兵器。
- 清场另有少量灵魂奖励。

### 赐福（每殿三选一，随机池 8 种）

判官朱印（伤害）、风火轮（移速+冲刺）、还魂草（生命上限）、阴阳眼（暴击）、
摄魂诀（灵魂+吸血）、缩地符（攻速）、铁布衫（减伤）、孟婆慈悲（回血+药）。

### 元魂 · 永久成长

战败或通关后，本轮所得灵魂的 **15%** 会留存为**元魂**（通关另有大额奖励）。
在标题页「阴德殿」里可买：

- 金刚不坏：初始生命上限 +15（最高 5 级）
- 天生神力：初始伤害 +8%（最高 5 级）
- 招魂幡：开局灵魂 +15（最高 5 级）
- 葫芦：开局回魂丹 +1（最高 2 级）

## 四、编译

### MSVC（Visual Studio）

在「x64 Native Tools Command Prompt」里：

```
cl /nologo /O2 /utf-8 diyu.c /Fe:diyu.exe
```

或者直接双击 `build.bat`（会自动寻找 vcvars64.bat 或 MinGW 的 gcc）。

### MinGW / GCC

```
gcc -O2 -std=c99 diyu.c -o diyu.exe
```

或：

```
make
```

Linux 下同样 `make`，无需额外链接库（Windows 版自动链接 `user32.lib` / `kernel32.lib`）。

## 六、技术实现要点

- **渲染**：整帧写入自绘字符缓冲，一次 `fwrite` 输出，配合 `\033[H` 归位与逐行 `\033[K` 擦除，无闪烁；16 色 ANSI 前景 + 黑底。
- **输入**：Windows 用 `GetAsyncKeyState` 做真实按键保持（按住 J 可连击），非 Windows 用 `termios` 原始模式 + 超时保持。
- **战斗**：30 FPS 定步逻辑、扇形/线形判定、攻速/暴击/吸血/击退、受击无敌帧、冲刺分步移动防穿墙。
- **AI**：游魂追击、阴兵蓄力冲锋、骨妖远程放风筝、牛头马面精英、阎罗王四段循环弹幕；被墙挡住时沿墙侧滑 + 脱困吸附。
- **地图**：每殿随机生成断碑/彼岸花/忘川水/牢笼石柱，并做一次洪泛填充把走不到的死角封成石壁，保证可达。
- **存档**：exe 同目录 `difu_save.dat` 纯文本，记录元魂与永久强化等级。

### 开发者自检参数

```
diyu.exe --sim 20000              # 无界面机器人自检
diyu.exe --sim 5000 --stage 3     # 直达阎罗殿测 Boss
diyu.exe --sim 5000 --god         # 无敌机器人，验证通关结算
diyu.exe --sim 200 --trace        # 打印逐帧状态
```

## 七、小提示

- 冲刺自带无敌，是躲「万魂环」和阴兵冲锋的关键。
- 贴身时出手会自动软锁定最近敌人，不必刻意调朝向。
- 前期优先买回魂丹和淬炼棍子，比急着解锁贵兵器更稳。
- 奈何桥只有中间一条道，别被远程骨妖堵在桥头。

## 八、开源

本项目采用 [MIT License](LICENSE)。欢迎提 Issue、提 PR：新的兵器、新的地府关卡、
新的阎罗王弹幕、Linux/macOS 终端适配，或者把界面做得更好看，都很欢迎。

- 源码是单文件 `diyu.c`，改起来不用先理解一堆模块。
- 提交前建议跑一遍 `diyu.exe --sim 20000`，内置机器人会把四关和 Boss 都走一遍。
- 二进制 `diyu.exe` 仅用于方便试玩，请以源码编译为准。

### 仓库地址 / 发布自己的 Fork

本仓库：<https://github.com/k4m1c0lt/diyu-underworld>（公开，MIT 协议）。

Fork 之后想发布自己的版本，有两种方式：

- 双击 `publish.bat`，输入 GitHub 用户名即可（检测到 `gh` 会自动建公开仓库并推送）。
- 或者先在 GitHub 建好名为 `diyu-underworld` 的空仓库，再执行：

```bash
git remote add origin https://github.com/<你的用户名>/diyu-underworld.git
git push -u origin main
```

> 某些受限网络会拦掉 `github.com` 的 Git 传输（但 `api.github.com` 仍可达）。此时用 REST API 方案：

双击 `publish_api.bat`，按提示粘贴 Personal Access Token（输入不回显、不落盘），
脚本会通过 GitHub REST API 创建公开仓库并把 `git ls-files` 里的全部文件打成单个初始提交上传。
等价的手工方式：

```bash
set GITHUB_TOKEN=<你的 PAT>
python publish_api.py
```

> 细粒度 PAT 通常无权新建仓库，遇到创建失败时请先在 <https://github.com/new>
> 建一个名为 `diyu-underworld` 的空公开仓库，再重跑脚本。发布完记得撤销 token。
